# Орбита — обновления для SideStore

Установочные пакеты Орбиты для iOS 17+. Каждый пользователь подписывает приложение собственным Apple Account через SideStore.

Адрес источника: https://raw.githubusercontent.com/TEREN7II/orbit-updates/main/source.json

Добавьте его один раз в SideStore → Sources → +. Для уже установленной Орбиты используйте тот же Apple Account; не удаляйте приложение ради обновления.

Новые версии появляются в My Apps после проверки источников; установка — кнопкой Update при подключённых Wi-Fi и LocalDevVPN. Продление подписи (Refresh) — отдельное действие.

В этом репозитории только каталог, иконка и неподписанные IPA. Рабочие базы, аккаунты и сертификаты сюда не входят.
